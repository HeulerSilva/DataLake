## 🧭 Overview

This repository is a collection of independent, production-inspired labs built on **Databricks**, covering the practical foundations of a modern Lakehouse workflow — from raw DataFrame manipulation to governed Delta tables, version history, and external BI/API integration.

Each subfolder below is a self-contained project with its own detailed README.

## 🗂️ Labs

| # | Project | Focus | Stack |
|---|---------|-------|-------|
| 01 | [DataFrame_Base1 — PySpark & Delta Lake Fundamentals](./DataFrame_Base1) | DataFrame operations, Delta Lake versioning & Time Travel, external connectivity via Databricks SQL Connector | PySpark · Delta Lake · Unity Catalog |
| 02 | [ETL_Base1 — IBGE Districts Data Pipeline](./ETL_Base1) | End-to-end ETL from a public REST API (IBGE) into a governed Delta table, with nested schema handling | PySpark · Delta Lake · REST API |
